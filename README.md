# SALSTM-LWARO-Emotion-Recognition
This study presents SALSTM-LWARO, a multimodal emotion recognition framework. It integrates SA-LSTM with a novel LWARO algorithm for hyperparameter optimization to overcome local optima. Using BERT (text), ResNet (video), and MFCC (audio), it achieved 97.73% accuracy on the SAVEE dataset, outperforming models like SER-XGBoost.
